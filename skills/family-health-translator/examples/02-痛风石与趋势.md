# 老年线：痛风石数值降了，仍未达到严格目标

全部虚构。示例中的「虚构片甲」不是可用药品；时间和剂量只演示原样转录。使用专用临时目录：

```sh
export DEMO_STORE="$(mktemp -d)/profiles"
printf '%s\n' '{"alias":"示例甲","age_band":"65-79","sex":"男","conditions":["痛风","痛风石"],"medications":["氢氯噻嗪"],"allergies":[],"targets":{}}' | python3 scripts/health.py --store "$DEMO_STORE" create --person example-tophi --scope adult --consent
printf '%s\n' '{"scope":"adult","measurements":[{"metric":"血尿酸","value":360,"unit":"μmol/L","date":"2026-10-01","series":"same-lab"}]}' | python3 scripts/health.py --store "$DEMO_STORE" review --person example-tophi --persist
printf '%s\n' '{"scope":"adult","measurements":[{"metric":"血尿酸","value":300,"unit":"μmol/L","date":"2026-11-01","series":"same-lab"}],"schedule_verified":true,"schedule":[{"drug":"虚构片甲","time":"08:00","dose":"1 片","source":"现行处方"}]}' | python3 scripts/health.py --store "$DEMO_STORE" review --person example-tophi --persist
```

## 第二次输出应有

1. **第一句结论**：1 项超出对照线：血尿酸。
2. **分级表**：🔴 血尿酸 300 μmol/L「正好到线，目标不含这个数」，目标 `<300`（严格小于）。下面一行：比 2026-10-01 下降了 60 μmol/L，变化不等于病情变化。
3. **大字版用药时间表**（本次给了核对过的处方才出现）：`08:00 ｜ 虚构片甲 ｜ 1 片（现行处方原样转录）`。
4. **复诊与提醒**：先问超线怎么处理、何时复查；告诉医生有痛风，带上用药清单；不要自行停药或调量。
5. **固定两行就医提示**、念给爸听、末尾出处。
