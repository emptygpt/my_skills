# 一般成人线：同一张化验单，两种结论

全为虚构。以下命令在 Skill 目录执行。首次建档的同意仅为演示，不代表采集真实病史。使用新建临时目录，不触碰实际档案：

```sh
export DEMO_STORE="$(mktemp -d)/profiles"
printf '%s\n' '{"alias":"示例甲","age_band":"20-59","sex":"男","conditions":[],"medications":[],"allergies":[],"targets":{}}' | python3 scripts/health.py --store "$DEMO_STORE" create --person example-plain --scope adult --consent
printf '%s\n' '{"alias":"示例乙","age_band":"20-59","sex":"男","conditions":["痛风"],"medications":[],"allergies":[],"targets":{}}' | python3 scripts/health.py --store "$DEMO_STORE" create --person example-gout --scope adult --consent
for PERSON in example-plain example-gout; do
  printf '%s\n' '{"scope":"adult","measurements":[{"metric":"血尿酸","value":400,"unit":"μmol/L","date":"2026-10-01","reference":{"min":210,"max":420},"series":"fasting-a"}]}' | python3 scripts/health.py --store "$DEMO_STORE" review --person "$PERSON" --persist
done
```

## 两份输出应有

1. **第一句结论**：示例甲「能对照的项都在范围内」（不代表排除疾病）；示例乙「1 项超出对照线：血尿酸」。
2. **分级表**：示例甲是 ✅（虚构报告的 210–420 区间内）；示例乙同一个 400 是 🔴，高出 40，痛风目标 `<360 μmol/L`。两份都没有可比历史，趋势只说一次。
3. **没有处方就没有药表**；复诊问题最多 3 个，第 1 个加粗。
4. **固定两行就医提示**（🚨 马上打 120／🏥 尽快就医），然后是念读稿，出处在末尾（示例乙为《中国高尿酸血症与痛风诊疗指南（2019）》问题 3）。本次分别写入对应档案。

以医生意见为准
