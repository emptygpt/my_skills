# 同一张化验单，两种结论

全为虚构。以下命令在 Skill 目录执行。首次建档的同意仅为演示，不代表采集真实病史。使用新建临时目录，不触碰实际档案：

```sh
export DEMO_STORE="$(mktemp -d)/profiles"
printf '%s\n' '{"alias":"示例甲","age_band":"60-79","sex":"男","conditions":[],"medications":[],"allergies":[],"targets":{}}' | python3 scripts/health.py --store "$DEMO_STORE" create --person example-plain --scope adult --consent
printf '%s\n' '{"alias":"示例乙","age_band":"60-79","sex":"男","conditions":["痛风"],"medications":[],"allergies":[],"targets":{}}' | python3 scripts/health.py --store "$DEMO_STORE" create --person example-gout --scope adult --consent
for PERSON in example-plain example-gout; do
  printf '%s\n' '{"scope":"adult","measurements":[{"metric":"血尿酸","value":400,"unit":"μmol/L","date":"2026-10-01","reference":{"min":210,"max":420},"series":"fasting-a"}]}' | python3 scripts/health.py --store "$DEMO_STORE" review --person "$PERSON" --persist
done
```

## 两份输出应有

1. **大白话解读**：示例甲的 400 μmol/L 在虚构报告的 210–420 区间内，不代表排除疾病。示例乙的同一数值未达到痛风血尿酸目标 `<360 μmol/L`；出处是《中国高尿酸血症与痛风诊疗指南（2019）》问题 3。两份都没有可比历史，本次分别写入对应档案。
2. **大字版时间表**：未获得经确认的现行医嘱，不生成。
3. **复诊问题**：在我的情况下应看哪个目标，什么时候复查？
4. **就医警讯**：新发胸痛、突然单侧无力、突发剧烈头痛、意识改变、呕血或柏油样黑便等联系急救；高热不退尽快就医。
5. **能念的话**：单子整理好了，带上原单问医生哪些要复查，药按现行医嘱，不自己改。

以医生意见为准
