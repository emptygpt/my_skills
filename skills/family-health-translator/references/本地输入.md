# 本地输入约定

以下数据均为虚构；从 Skill 目录直接使用示例，或用可信的本机前端将 JSON 送给标准输入。不要在共享终端、模型工具调用或在线编辑器里照抄真实资料。脚本不会自动取证或识别照片；若用离线 OCR，先人工逐项核对。

可信本机 POSIX、Python 3.9+，无网络依赖。运行 `python3 scripts/health.py --help` 查看入口，子命令也有 `--help`。默认从当前目录的 `家人健康档案/` 读取，建议在子命令之前加 `--store` 指定 Skill 包外的专用非同步目录。首次建档创建权限 700 的目录，每人一份权限 600 的 JSON；同一份档案不要同时开启多个写入。无法执行脚本时，按 `解读与档案.md` 使用同字段的私有 Markdown 档案。

| 操作 | 命令 |
|---|---|
| 本人单独同意后建档 | `python3 scripts/health.py create --person demo --scope adult --consent` |
| 查看 | `python3 scripts/health.py show --person demo` |
| 修改 | `python3 scripts/health.py update --person demo` |
| 解读并经本人同意追加 | `python3 scripts/health.py review --person demo --persist` |
| 不建档或只读 | `python3 scripts/health.py review`（加 `--person demo` 只读相应档案） |
| 撤回并删除 | `python3 scripts/health.py delete --person demo --confirm`（不清除备份、终端记录或打印件） |
| 当前症状辅助扫描 | `python3 scripts/health.py triage` |

**建档输入**（示例编号 `demo` 与代称均为虚构）：

```json
{"alias":"示例长辈甲","age_band":"65-79","sex":"男","conditions":["痛风"],"medications":[],"allergies":[],"targets":{}}
```

- 一般成人线填 `18-19` 或 `20-59`；老年线填 `60-64`、`65-79` 或 `80+`。旧值 `60-79` 兼容，需重新核对才能使用老年血压目标。年龄为 `未知` 或未提供时不解读。`sex` 可填 `男`、`女`、`未知`。病名、药名和过敏名用短标签；空列表不表示已排除。不要记录出生日期或真实身份，不从数值推断病史。
- 老年线新增可选的 `older_diabetes`：`self_care` 填 `independent`（独立或有可靠协助）、`limited`（管理受限）、`dependent`（无法自我管理）；`hypoglycemia` 填 `low`（已确认低风险）、`risk`（已确认有风险）、`severe_history`（有严重低血糖史）；`health` 填 `early_stable`（新诊断/短病程且情况稳定）、`moderate`（医生确认中等并发或伴病且适宜过渡阶段）、`major_impact`（医生确认健康严重受影响且适宜可接受档）。不明项省略；不得从药名、年龄或慢病数量猜。`ldl_risk` 只抄医生确认的二级预防风险档，填 `very_high`（极高危）或 `ultra_high`（超高危），不是自评字段。
- 这些新增敏感字段仅在资料本人单独同意新增处理后保存：`create` 或 `update` 加 `--older-consent`。分层对象按整组替换，清除可传 `{"older_diabetes":{},"ldl_risk":null}`；不需要同意就不保存，两字段也可以只在一次性 `context` 中使用。
- 医生明确改目标后，`update` 的 JSON 例：`{"targets":{"血尿酸":{"op":"<","value":300,"unit":"μmol/L"}}}`。可选 `op` 为 `<`、`<=`、`>`、`>=`；`{"targets":{"血尿酸":null}}` 删除该指标的个人目标，不删除其他目标。医生个人血压目标请明确写 `bp_context`（`clinic`、`home` 或 `ambulatory`），老档缺少此字段只与诊室数据比。修改病史、用药、过敏时是整组替换。数值没有单位或比较方向时不要写。

**解读输入**：

```json
{"scope":"adult","context":{"age_band":"20-59"},"symptoms":"","critical_flag":false,"measurements":[{"metric":"血尿酸","value":400,"unit":"μmol/L","date":"2026-10-01","reference":{"min":210,"max":420},"series":"same-lab-fasting"}]}
```

- `scope`：`adult` 表示已确认非孕成年人；`minor`、`pregnant` 或 `unknown` 不执行成人比较。无年龄不会输出结论；急症和报告危急值优先，不等年龄。`symptoms` 只写当前或刚发生的症状；`critical_flag` 只代表原单标注危急值，不等于高低箭头。
- 一次性解读用 `context` 提供年龄段，可附档案里除 `alias` 以外的已确认字段，无需建档；用 `--person` 时不提供 `context`，只用该档案的年龄和资料。老年共病例见[示例](../examples/04-老年多病共存.md)。
- `measurements` 只放已核对数据。`reference` 是原单印明的闭区间；不把单侧参考线、治疗目标、文字条件硬改为双侧区间。无区间就省略。`lab_range_applicable` 仅在实验室确认方法及参考人群适用 WS/T 404.5（肌酐/尿素）或 WS/T 405（血红蛋白）后填 `true`。`series` 仅同人同单位、采样条件及方法可比时共用；不把随机、餐后和空腹血糖混比。
- 支持血尿酸、血清肌酐、血清尿素、空腹血糖、血糖、糖化血红蛋白、收缩压、舒张压、四项常规血脂及丙氨酸/天门冬氨酸氨基转移酶。按原单位，不自动换算；`μmol/L` 使用希腊小写 μ。血压两项分开输入：`bp_context` 填 `clinic`（诊室）、`home`（家庭）、`ambulatory`（动态）或 `unknown`；没有明确场景不猜。输入医生个人血压目标前，操作者需确认测量场景匹配。
- 只对已确认适用于一般成人目标的诊室血压或糖化血红蛋白加 `general_goal_applicable: true`。仅凭年龄和病名不能填 `true`；病史不清、可能需个体化或已知医生另有要求时，省略或填 `false`。团队测试中的 `true` 表示虚构场景已确认，不是默认值。这两个字段都不写入历史。
- 老年线仅在诊室目标确实适用时，为已确诊高血压者的诊室读数加 `older_bp_applicable: true`。即使填写，相关合并症仍须问医生。`ldl_baseline` 仅传同一人已核对的治疗前 LDL-C 实测值，单位同为 `mmol/L`。肾功能填 `估算肾小球滤过率` / `mL/min/1.73m²`；骨密度填 `骨密度T值` / `SD`，适用人群和报告所测部位、DXA 方法无疑问才填 `dxa_applicable: true`；血红蛋白填 `血红蛋白` / `g/L`。这些适用性和治疗前基线均不写入指标历史。
- 现行医嘱时间表经本人确认后才给 `"schedule_verified":true` 和 `"schedule":[{"drug":"虚构片甲","time":"08:00","dose":"1 片","source":"现行处方"}]`。`source` 只填 `现行处方` 或 `药师确认`；`time` 原样转录 `HH:MM`、明确的某餐前/后或 `睡前`。剂量只接收原指令中清楚的单次量与单位，不用每片规格代替。过敏、重复条目、变化中的医嘱、间隔服用或多种条件无法核对时，不制作表。
